# GenAI A16: Ensemble Learning

## Overview
This project explores ensemble learning techniques using Python and Scikit-learn. It compares Bagging, AdaBoost, Random Forest, and a single Decision Tree classifier.

## Objectives
- Understand Bagging and Boosting.
- Train a Bagging Classifier.
- Train an AdaBoost Classifier.
- Build a Random Forest Classifier.
- Compare model performance using test accuracy.
- Identify important features using Random Forest.

## Dataset
Breast Cancer Wisconsin (Diagnostic) dataset.

- Samples: 569
- Features: 30 numerical features
- Target: Diagnosis (classification)

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Tasks Completed

### Task 5: Bagging vs Boosting
- Trained a Bagging Classifier.
- Trained an AdaBoost Classifier.
- Compared their test accuracy.

### Task 6: Random Forest
- Trained a Random Forest Classifier.
- Compared it with a Decision Tree and Bagging.
- Examined feature importance.

## Evaluation
Model performance is evaluated using test accuracy.
Actual accuracy values will be added after running the notebook.

## How to Run
1. Clone this repository.
2. Install the required libraries.
3. Open the Jupyter Notebook.
4. Run the cells in order.
